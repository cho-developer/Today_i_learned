1. new: C에서의 malloc. malloc과 마찬가지로 heap영역에다 메모리할당.  malloc과 마찬가지로, char*에게는 수정 가능한 char배열의 주소를 넘겨줌.

    1-1형식:
    T* pointer = new T 변수//T는 임의의 타입.

    1-2 malloc과의 차이점:
    new도 malloc과 마찬가지로 할당한 메모리의 주소값을 반환. but new 는 생성자도 실행(호출)시켜 완전한 객체를 만듦.
    타입 캐스팅도 안해도됨.

    
2. delete: C에서의 free.
    형식:
    delte pointer;//delete 로 해제할 수 있는 메모리 공간은 사용자가 new 를 통해서 할당한 공간만 가능, 즉 heap 공간에 있는 메모리를 
    제거할때만 delte 사용ㄱㄴ.

3. 포인터-배열의 new와 delete
    T* pointer = new T[size];
    >>T는 임의의 타입. pointer는 크기가 size인 T타입 배열 가르킴.

    delete[] pointer;

4.  객체의 할당 위치
    4-1 스택:
    Marine marine1 = Marine(1, 3); //객체자체가 스택영역에 할당. so. 자신이 속한 블록({})벗어나는 순간 메모리가 자동해제.
    
    4-2 힙:
    Marine* marine1 = new Marine(1, 3); //객체가 힙 영역에 생성되고, 포인터 변수 marine1에 주소가 저장. so. 개발자가 직접 delet해줘야함.
