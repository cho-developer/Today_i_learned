1. new: C에서의 malloc.
    형식:
    T* pointer = new T 변수//T는 임의의 타입.

    
2. delete: C에서의 free.
    형식:
    delte pointer;//delete 로 해제할 수 있는 메모리 공간은 사용자가 new 를 통해서 할당한 공간만 가능, 즉 heap 공간에 있는 메모리를 
    제거할때만 delte 사용ㄱㄴ.

3. 포인터-배열의 new와 delete
    T* pointer = new T[size];
    >>T는 임의의 타입. pointer는 크기가 size인 T타입 배열 가르킴.

    delete[] pointer;
