0. 참조자(reference): &.

1. 기능: 변수의 또다른 이름 이라고 컴파일러에게 알려주는 것. 따라서 
 another_a 에 어떠한 작업을 수행하든 이는 사실상 a 에 그 작업을 하는 것과 같음.

2. 형식: 
 가르키고자 하는 타입뒤에 &붙이기. 
 e.g.,)

 double &another_a=a;//
 double a의 참조자를 만드려면 double&.

 int *&another_a=a;//
 int* 와 같은 포인터 타입의 참조자를 만드려면 int*&.
  
3. 참조자와 포인터의 차이:
    처음 레퍼런스 정의시 반드시 누구의 별명으로 할지 명시해야함.

    한번 어떤 변수의 참조자로 정의 되어버리면, 더 이상 다른 변수를 참조못함.

    e.g.,)
    int a = 10;
    int &another_a = a; // another_a 는 이제 a 의 참조자!

    int b = 3;
    another_a = b; //a=b와 동치. another_a보고 다른 변수b를 가르키라는것이 X. a에b를 대입하라는 의미.
    &another_a = b;//&a=b와 동치.

    레퍼런스는 메모리 상에 존재하지 않을 수 도 있음.//어차피 another_a 가 쓰이는 자리는 모두 a 로 바꿔치기 하면 되니까.

4. 레퍼런스의 레퍼런스,레퍼런스의 배열, 레퍼런스의 포인터는 존재할 수 없음.//레퍼런스는 주소값이 존재X여서.

5. 배열의 레퍼런스//포인터와는 다르게 배열을 참조하기 위해선 반드시 배열의 크기를 명시해야함.

    e.g.,)
    int arr1[3] = {1, 2, 3};
    int(&ref1)[3] = arr;

   ref[0] = 2;
   ref[1] = 3;
   ref[2] = 1;

    int arr2[3][2] = {1, 2, 3, 4, 5, 6};
    int (&ref2)[3][2] = arr;
    
6. 레퍼런스를 리턴하는 함수
    e.g.,)
    int& function(int& a) {
    a = 5;
    return a;
    }
