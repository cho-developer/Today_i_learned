3. object(객체)

    3-1 개념:
     현실세계에 존재하는 것을 컴퓨터로 최대한 구현한 것.객체는 자기 만의 정보를 나타내는 변수들과, 이를 가지고 어떠한 작업을 하는 함수들로 둘러싸여있음.

   e.g.,)
    핸드폰의 경우 '전화를 한다', '문자를 보낸다' 와 같은 것들은 '핸드폰이 하는 것' 이므로 함수로 추상화시킬 수 있고,핸드폰의 상태를 나타내는 것들, 예를 들어서 자기 자신의 전화 번호나 배터리 잔량 같은 것은 변수로 추상화(컴퓨터가 처리할수 있게 하는것==추상화).

    3-2 함수들이 변수들을 둘러싸고 있는 이유:
     변수들이 외부로 부터 '보호' 되고 있기 때문. 즉, 외부에서 어떠한 객체의 인스턴스 변수의 값을 바꾸지 못하고 오직 객체의 인스턴스 함수를 통해서만 가능(캡슐화).

    3-3 용어 
    이러한 객체의 변수나 함수들을 보통 인스턴스 변수(instance variable) 와 인스턴스 메소드(instance method).

4. 함수의 overloading// overload: 과적하다.
    4-1:
     C++ 에서는 같은 이름을 가진 함수가 여러개 존재해됨. 함수의 이름이 같더라도 인자가 다르면 다른 함수.
    >> 같은 이름의 함수를 호출 할때 구분법: 
    함수를 호출 하였을 때 사용하는 인자를 보고 결정

    e.g.,)

    void print(int x) { std::cout << "int : " << x << std::endl; }
    void print(char x) { std::cout << "char : " << x << std::endl; }
    void print(double x) { std::cout << "double : " << x << std::endl; }

    
    print(a);
    print(b);
    print(c);

    4-2 자기(인자)와 정확히 일치하는 매개변수를 가지는 함수가 없을땐: '자신(인자)와 최대로 근접한 함수'를 찾아 들어감. 

5. 일반함수 vs 맴버함수 
  맴버 함수:
  class이름:: 을 함수 이름 앞에 붙여주게 되면 이 함수가 "클래스에 정의된 함수" 라는 의미를 부여.

  일반함수:
  함수 이름앞에서 반환형만 있으면 일반함수.

  e.g.,)
  void Date::ShowDate(){}// ShowDate함수는 Date클래스에 정의된 맴버함수. 
  void ShowDate(){}//일반함수.
