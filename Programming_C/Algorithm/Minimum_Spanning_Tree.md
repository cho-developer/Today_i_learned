0. 신장 트리(Spanning_Tree): 그래프 내에 모든 정점을 포함하는 트리. 하나의 그래프에는 여러 신장 트리가 존재 할수 ㅇ.
    0-1 신장트리 조건
    조건1: 모든 정점이 연결되어 있어야.
    조건2: 사이클이 존재X.
    조건3: 간선의 수는 정점의 수보다 반드시 하나 적어야함. 
    //간선 수==정점 수 되면 조건 2위배(사이클이 필연적으로 발생.)
    //간선수 == 정점수-2 되면 조건1 위배.(모든 정점이 연결 안됨.)

1. 최소 신장 트리(MST==Minimum_Spanning_Tree): 간선의 가중치 합이 가장 최소인 신장 트리.
    
    1-1 대표 알고리즘
    Prim(프림) 알고리즘.
    Kruskal(크루스칼) 알고리즘.


2. Prim 알고리즘: Greedy알고리즘. 
    그래프 유형: 무방향, 가중치 그래프
    전략:
        1>출발: 임의의 정점에서 시작.
        2>현재 MST에 연결된 간선중(==선택 되지 않은 간선 && MST의 정점 집합에 인접한 간선) 가중치가 가장 적은 간선을 선택. 해당 간선으로 연결된 새 정점을 MST에 추가.  
        3> 사이클이 생기지 않도록.
        4>종료: 모든 정점이 MST에 포함 될때까지 반복.
    
    구현법: 최소 힙(우선순위 큐)+ 인접 리스트 방식

    최종 시간 복잡도: O(ElogV)  == 간선 추가시 우선순위 큐 연산(O(logV)) + 모든 간선을 한번씩 확인(O(ElogV))
