0. 용어
    그래프 순회: 모든 vertex를 각각 한번씩 방문.(재방문 금지.)
    DFS(==Depth First Search): 깊이 우선 탐색
    BFS(==Breadth First Search): 너비 우선 탐색


1. DFS
    1-1구현법: stack or 재귀호출. 같은 vertex를 재방문 하는걸 막기위해 불 방문 배열(Boolean Visitd Array)use.
    
        1-1-1stack구현: 
        1> 출발 정점잡고 출발정점을 stack에 push.
        2> stack이 비어있는지 확인//stack이 빔==순회 끝
        3> 만약 비어 있지 않다면 정점pop(==방문.)
        4> pop한 출발 정점과 인접한 정점들을  push. 
        5> 2>,3> 실행. 3>에서 pop했던 정점과 인접한 정점들 push(이때 stack에 이미 있는 정점들은 다시 push안하고 new 정점들만 push.)
        ->> 5>반복. 
        stack으로 구현: 출발 정점이 같아도 push하는것에 따라 DFS가 달려질수 있음.
