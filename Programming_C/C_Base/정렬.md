1. 정렬의 종류
  1) 버블정렬:이중 포문. 마지막 인덱스 부터 정렬.O(N^2)
  2) 선택 정렬: 정렬된 인덱스 제외하고 순회. 선택.앞 인덱스부터 정렬.O(N^2)
  3) 삽입 정렬:옆 인덱스의 데이터를 비교. 위치 교환 하지  않아도 되면 그대로. 교환해야 한다면 위치 교환. 해당 데이터가  교환되지 않을때까지 이전 인덱스와 교환 반복.   O(N^2)

  4) 퀵 정렬:꽃. 기준 값(pivot)으로 편을 나눠서 정렬(==분할해서 정복).분할 정복 방법론. pl, pr, pivot. pl과 pr이 크로스 되는 그 시점에서 pL 왼쪽 편: pivot 이하. pR 오른쪽 편: pivot 이상값 으로 정렬됨. O(NlogN).
  5) 병합 정렬: 임마 하기 전에 정렬된 2개 배열 병합 하는법(3개의 배열 인덱스를 가르킬 변수 3개use) 알아야함.
   구현법: 원소가 1개 될때까지 나누기(따로 배열 만들어서 나누는게x. left, right,middle 이용해서 개념적으로 나누기. ). 2의 거듭제곱 크기 만큼 병합(병합 할때마다 정렬 되게 병합).O(NlogN).
  6) 힙 정렬: 정렬하려는 배열을 heapify. 힙화된 배열의 첫번째 원소와 마지막 원소를 exchange. 마지막 인덱스는 정렬된거임. 또 힙화,"정렬안된 마지막 인덱스"와 exchange. ->> 반복. heap자료구조.O(NlogN).

  7) 버킷 정렬:필요조건(데이터의 범위가 정해짐) 충족시O(N).
  정수범위+1의 크기인 배열(==양동이==bucket)을 만듦(0인덱스는 더미). 인덱스에 해당하는 정수를 발견시 bucket 해당 인덱스에다 ++. 인덱스 내의 데이터 만큼 배열을 채움.


void bubble_sort(int *arr, int size){

for(int i=0; i<size-1; i++){

    for(int k=0; k<i; k++){

        if(arr[k]>arr[k+1]){
            int temp=arr[k];
            arr[k]=arr[k+1];
            arr[k+1]=temp;
        }


    }

}

}

void select_sort(int *arr, int size){

     int min,temp;

     for(int i=0; i<size-1; i++){
        min=i;
        for(int j=i+1; j<size; j++){
            if(arr[min]>arr[j]){
            min=j;
               
            }
        }
        temp=arr[i];
        arr[i]=arr[min];
        arr[min]=temp;
     }

}


void insertion_sort(int* arr, int size) {

    for (int i = 1; i < size; i++) {
        
        for (int j = i - 1; j >= 0; j--) {
            if (arr[j] <= arr[j+1]) { break; }

            int temp = arr[j];
            arr[j] = arr[j + 1];
            arr[j + 1] = temp;
        }
    }
}

void quick_sort(int *arr, int left, int right){


int pL=left;
int pR=right; 
pivot=arr[(pL+pR)/2];


while(pL<= pR){

    while(arr[pL]<pivot) pL++; 
    while(arr[pR]>pivot) pR--;

int temp=arr[pL];
arr[pL]=arr[pR];
arr[pR]=temp;
pL++;
pR--;
}

if(left<pR)
quick_sort(arr, left,pR );

if(right>pL)
quick_sort(arr, pL,right );


}
 


void merge(int *arr1, int size1, int *arr2, int size2, int *merge){

    int idx1=0;
    int idx2=0;
    int idxm=0;
    while(idx1<size1 && idx2< size2){
        
        if(arr1[idx1]<=arr2[idx2]){
            merge[idxm++]=arr1[idx1++];
        }

        else if(arr1[idx1]>arr2[idx2]){
            merge[idxm++]=arr2[idx2++];
        }
    }

    while(idx1<size1){
        merge[idxm++]=arr1[idx1++];
    }

    while(idx2<size2){
        merge[idxm++]=arr2[idx2++];
    }


}  // 병합 정렬을 위해 알아야하는 병합.

void bucket_sort(int *arr, int size, int range)
{

int *bucket=(int *)calloc(range,sizeof(int));

for(int i=0; i<size; i++)
{
    bucket[arr[i]]++;
}

int idx=0;

for(int j=1;j<range; j++)
{
    while(bucket[j])
    {
        arr[idx++]=j;
        bucket[j]--;

    }
}
free(bucket);
}
